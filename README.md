## 🚀 5-Minute Quick Start

### 1. Instant Local Preview
1. Simply double-click **`REDX-MOVIE-ULTIMATE.html`** or **`index.html`** to open in any web browser.
2. The application includes a preloaded high-definition Demo Cinema Vault for out-of-the-box browsing.

### 2. Connect Your Own TMDB API Key (Optional / Recommended)
1. Sign up for free at [themoviedb.org](https://www.themoviedb.org/signup).
2. Go to **Settings → API → Request API Key (Developer)**.
3. In REDX MOVIE, click the **🔑 API Key icon** in the top right.
4. Paste your 32-character key and click **Save & Activate**.

## 🌐 Instant Deployment Options

### Option A: Netlify Drop (Easiest - 30 seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `REDx MOVIE` folder (or `index.html`).
3. Your site gets a free live HTTPS URL instantly (e.g., `https://redx-cinema.netlify.app`).

### Option B: GitHub Pages
1. Create a repository on GitHub (e.g., `username.github.io` or `redx-movie`).
2. Push `index.html` to the repository.
3. Enable GitHub Pages under **Repository Settings → Pages**.

### Option C: Vercel
1. Import your GitHub repository to [Vercel](https://vercel.com).
2. Deploy as a static site with 1 click.
